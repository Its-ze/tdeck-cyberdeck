# T-Deck Cyberdeck Pages

Public installer and deck metadata for the T-Dongle CyberDeck control-unit firmware.

Live site:

```text
https://its-ze.github.io/tdeck-cyberdeck/
```

Deck marketplace index:

```text
https://its-ze.github.io/tdeck-cyberdeck/deck/marketplace-index.json
```

This public repo intentionally contains only the browser installer, ESP Web Tools manifest, generated firmware binaries, and non-secret app/marketplace metadata. Private backups, Meshtastic key material, local workbench state, and full local development artifacts stay out of this repo.
